TOEFL® 瞬間英作文

日本語を見て、英文を即座に書く。大学の授業とキャンパスで使う構文と表現を30項目で。

TOEFL® および TOEFL iBT® は ETS の登録商標です。本アプリは ETS とは一切関係のない非公式アプリで、ETS が推奨・承認したものではありません。

「TOEFL® 瞬間英作文」は、日本語の文を見てすぐに英語で言う・書く「瞬間英作文」で、TOEFL iBT® テストのライティングとスピーキングで使う構文と表現を身につける学習アプリです。構文と表現を30項目に分け、1項目50文、合計1,500文を収録。メール・ディスカッション（ライティング）とインタビュー（スピーキング）の練習もできます。無料・広告なし。アカウント登録は不要で、問題データはアプリに同梱、学習記録は端末内にだけ保存されます。AI 添削も端末の中だけで動きます。

  • 1,500構文・表現別の収録文
  • 30構文・表現の項目
  • 0円無料・広告なし

主な特徴

  • 構文と表現を30項目で体系的に 「高度な文法」「学術の論証」「語彙と表現」の3グループ、1項目50文。仮定法・関係詞・疑問文と間接疑問から、定義と分類・因果関係・研究とデータ・意見と理由、依頼と丁寧表現・句動詞・アカデミック動詞まで一周できます。トピック別（生物学・心理学・経済・歴史・キャンパス生活など16の分野）に横断して解くこともできます。
  • 入力モードと並べかえモード キーボードで英文を入力するモードと、単語カードを並べかえて英文を組み立てるモード。語や句を並べて文を作る Build a Sentence の練習にもなります。
  • 見落としやすい誤りに「惜しい!」のヒント 大文字・小文字や短縮形（I am / I'm）の違いは気にせず判定します。一方で冠詞の抜けや -s の付け忘れなどは不正解とし、「惜しい!」のヒントでどこが違うかを教えます。
  • すべての文に構文と語句の解説 なぜその形になるのかを短く解説。言いかえができる文には別解も用意しています。
  • ライティング（Write an Email / Write for an Academic Discussion） メールは、書き出し・依頼・提案・結びに使う文の型60文と、場面ごとの模範メール30本。ディスカッションは、教授の問いに学生2人の投稿をふまえて答える模範投稿30本と、立場・理由・例を述べる文の型60文。1文ずつ組み立てるモードと全文を自分で書くモードがあり、語数カウンタとセルフチェック付きです。
  • スピーキング（Listen and Repeat / Take an Interview） キャンパスの案内や講義の一文を日本語からすぐ英語にするリピート練習の短文60文。インタビューは、経験や意見を答える文の型60文と、質問ごとの模範回答40本。英文はすべて読み上げで聞けます。
  • 苦手の復習と実力テスト 答えた結果から「苦手」になった文だけを集めて復習できます。項目ごとの実力テストは、10問を1問も間違えずに解けたら合格です。
  • AI添削は端末の中だけで（対応端末のみ） 間違えた文やライティングの答えに、端末の OS が提供する AI（iPhone の Apple Intelligence、Android の AICore）がコメントします。書いた文が外部に送信されることはありません。対応していない端末ではこの機能は表示されません。AI のコメントは参考情報で、ETS の採点基準や監修とは関係ありません。
  • 読み上げ・学習記録・リマインダー 英文の読み上げ、苦手な文のマイリスト、習得した文・毎日の解答数の記録、学習のリマインダー通知（設定でオンにしたときだけ）。
